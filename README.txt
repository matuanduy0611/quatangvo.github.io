WEBSITE CHÚC MỪNG 20/10/2026 — HTML, CSS, JAVASCRIPT (KHÔNG PHP)
=================================================================

CẤU TRÚC
- index.html
- style.css
- script.js
- assets/galaxy-heart-background.png (ảnh nền Galaxy được tạo riêng)
- assets/50-nam-ve-sau.mp3 (bạn thêm tệp nhạc vào đây)

CÁCH MỞ
1. Giải nén ZIP.
2. Thêm bản nhạc MP3 bạn có quyền sử dụng vào assets và đặt tên chính xác:
   50-nam-ve-sau.mp3
3. Mở index.html bằng trình duyệt. Không cần PHP hoặc máy chủ web.

LƯU Ý
- Website dùng HTML, CSS và JavaScript thuần.
- Trình duyệt thường chặn tự động phát âm thanh có tiếng. Trang sẽ thử tự phát,
  nhưng nếu bị chặn, hãy bấm nút ▶ ở góc trên bên trái.
- Gói không kèm bản ghi bài hát có bản quyền. Vui lòng tự thêm tệp nhạc mà bạn
  có quyền sử dụng.
- Bạn có thể chỉnh sửa lời chúc trong index.html và màu sắc/hiệu ứng trong style.css.
